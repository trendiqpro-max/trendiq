# TrendIQ — social media assets

Post cards and videos for @trendiqpro, served over raw.githubusercontent.com so
the scheduler can fetch them.

- `x/`         1600x900  @2x  — X in-feed cards
- `instagram/` 1080x1350      — Instagram feed cards (4:5)
- `tiktok/`    1080x1920      — TikTok videos, 5s, H.264 + silent AAC

`instagram-tiktok-captions.md` holds the adapted captions.
`CONTACT-SHEET.png` is all 14 cards at a glance.

Numbers on the Fed card were pulled live from the Kalshi and Polymarket public
APIs on 2026-09-15 and resolve 2026-09-16T17:55Z.
